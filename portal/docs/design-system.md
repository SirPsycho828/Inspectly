# Design System — Inspectly

> Generated by Design Overhaul skill. This document is the single source of truth for all design decisions.

## Design Direction

**Direction:** Fieldwork — warm, grounded, built for tradespeople who value craft over flash
**Signature Element:** Warm property photography as section backgrounds, walnut-toned navigation, editorial asymmetric layouts with subtle paper-like warmth throughout

## Animation

| Token | Value | Usage |
|-------|-------|-------|
| --duration-fast | 150ms | Micro-interactions (hover, focus) |
| --duration-normal | 250ms | State transitions |
| --duration-slow | 400ms | Page transitions, reveals |
| --easing-default | cubic-bezier(0.4, 0, 0.2, 1) | General motion |
| --easing-spring | cubic-bezier(0.34, 1.56, 0.64, 1) | Bouncy entrances |
| --easing-out | cubic-bezier(0, 0, 0.2, 1) | Exit animations |

**Signature Animation:** Content sections slide up with a gentle fade-in (translateY(16px) to 0, opacity 0 to 1) over 400ms with deceleration easing. Cards stagger-enter with 60ms delay between siblings. Feels like pages turning in a field notebook.
